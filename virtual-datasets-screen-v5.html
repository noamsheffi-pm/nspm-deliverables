All virtual datasets

A virtual dataset is a named DataPrime query, built with the Builder or written in DataPrime. Anyone with read on it can write source <name> anywhere, and the query runs as if its definition was typed there. H 11-10

ⓘ
A virtual dataset can have the same name as a dataset. The virtual one is read first. To read the dataset itself, put its name in quotes: source "default/logs".
