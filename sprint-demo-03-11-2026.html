LiveAI Units: Monthly Cycle and Team Limit

Want to cap AI use per team? Set a monthly limit. It blocks at that number.

What it is

AI units run on a monthly cycle, with a limit for each team.

What you get

The number on the screen is the number that blocks. When a team reaches its monthly limit, AI stops for that team only.

Before

Enforced per day for the whole account. A team limit did not block.

Related asks

MoneyGram (PIPE), Orcid (PIPE), H2O.ai (PIPE), FactSet, Tekion

ShippedPredefined User Dataset

Want a new feature to work on day one? Its dataset is already there.

What it is

A dataset that Coralogix creates and fills for you, shown as "Managed by Coralogix".

What you get

No setup. You set its retention, quota and access, like any of your datasets.

Before

You built the dataset and a routing rule first, or the feature screen stayed empty.

Built for

Code Agent sessions (ai.sessions.claude), the first feature that needs its data on day one

Good to know
  • Schema is fixed
  • Cannot be deleted or renamed
