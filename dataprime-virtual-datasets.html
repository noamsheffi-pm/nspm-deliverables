Rules this mock follows

      

        
It is the language, not ExploreAutocomplete, the name mark and the errors come from DataPrime tooling. Every editor and the API get the same behavior.

        
A virtual dataset is a full queryAny operator. It is read at query time, like a view. No schema tracking.

        
Errors point at the nameA problem inside the definition shows on the virtual dataset as a whole. It never points at a source inside it.

        
The virtual one is read firstsource transactions reads the virtual dataset. source "transactions", in quotes, reads the dataset itself.

        
No access to a source, no resultsIf the user cannot read a source inside the definition, the query does not run. Partial results are a later phase.

        
Open: definition on hoverThis mock shows the full definition on hover to users who may view it. CX-41805 lists hover as not phase 1. The permission does not hide the definition everywhere yet; that is accepted for now.
