File format

s3://<bucket>/<prefix>/year=YYYY/month=MM/day=DD/hour=HH/<file>.ndjson.gz
  • Gzipped NDJSON, one JSON object per line
  • Every record carries an event-time field
  • Records uniformly shaped, one malformed record fails its file
  • Partitioning is a preference, not a requirement. Your existing layout worked. Partitioning by hour makes the run faster on our side.

What we need from you

  • Scope of the first chunk. Which time range, how many hours, uncompressed size.
  • Dataset name to create for the imported data.
  • Retention tag. One tag, applied across all groups. Per-field retention is not supported yet.
  • Timeline. When you need the history available by.
  • Contacts. Who on your side owns the export and is our technical point of contact.

How a run finishes

  1. We read the partitions from your bucket.
  2. We import and write the result back to your bucket.
  3. You check the data and confirm it is correct.
  4. Once you confirm, we advise on removing the source data.

Your validation is the gate on deleting a source database, not ours. We will not tell you it is safe to delete before you have looked at the result yourself.
