Pipeline · TCO

Cost Control Reaches Spans

Graceful Span Cost ControlShipped

Stay inside your trace budget without going blind the moment you reach it.

Before

Span quota reached, ingestion blocks. Traces stop arriving, so the incident you are debugging goes dark.

→
Now

Quota fills and priority steps down in stages. Low-value traces degrade first, the ones you flagged as important keep arriving.

Value

Customers can size trace budget to what they actually need, instead of padding it to stay clear of a cliff. Cost control stops costing them visibility.

Show

TCO › Spans set two thresholds on a span policy, push usage up, and watch priority walk High to Medium to Low while the high-priority stream keeps flowing.

Priority Block on IngestRolling Out

Stop paying for the traces you already decided are worthless.

Before

Even the lowest priority still meant ingest, store and charge. The only way to not pay for a trace was to stop the service sending it.

→
Now

A Block priority drops matching spans at ingest. The trace view marks where data is absent because Block applied, so nobody debugs a gap blind.

Value

Customers can zero out spend on traffic they have judged has no value, without asking their engineers to change what services emit.

Show

TCO › Spans set a policy priority to Block, then open the trace view and point at the blocked-state indicator.

Monetization · Quota

Quota Becomes Movable

Unit-Based Quota RulesShipped

One quota currency across every data type, so a guarantee means the same thing everywhere.

Before

Quota was raw volume per pillar. A guarantee for logs and a guarantee for spans were not comparable, so budget could not move between them.

→
Now

Allocations are units. The same reservation reads identically in Quota Rules and Org Quota Manager, and is applied in the entity-type blocker.

Value

We can sell one number instead of per-pillar volumes, and a customer can shift budget between data types without renegotiating the contract.

Show

Quota Rules show a unit reservation on an entity type, then the same allocation expressed in Org Quota Manager.

↗ Roadmap card CX-38652 HaloProduct DesignTech WritingNimbus
Move Units Between TeamsRolling Out

Rebalance quota between teams in minutes, with no contract change and no call to us.

Before

One team starved while another sat on headroom. Moving capacity between them meant a commercial conversation.

→
Now

An org admin moves units in a drawer, sees the resulting split before committing, and locked allocations cannot be taken from the team relying on them.

Value

Admins self-serve every in-quarter capacity shuffle, with no sales touch. The lock is what makes that safe to hand over: a team keeps a guarantee that survives someone else rebalancing.

Show

Org Quota Manager › Move Units pick source and target, read the preview, then try to move a locked allocation and watch it refuse.

Monetization · Usage & AI

Usage Gets an Owner

Unified Usage AnalyticsShipped

One answer to "which team spent what, on which data", across the whole org.

Before

Usage lived per team. Answering a chargeback question meant exporting each team and reconciling the numbers by hand.

→
Now

Select the teams you are entitled to see, query them together, and get the same answer in DataPrime at org level.

Value

Platform teams can charge their business units back directly, which is what lets them keep adding teams. These are the accounts that grow by team count rather than by volume.

Show

Data Usage › multi-team query select three teams, run it, then run the equivalent org-level query in DataPrime to show it is the same engine.

Olly on the Quota SurfacesRolling Out

Ask about your consumption in the screen you are already looking at.

Before

Answering "why did we spend more this week" meant leaving the screen and writing a query, so whoever owned the budget had to ask someone who could.

→
Now

Olly sits inside Quota Rules, Org Quota Manager and Data Usage. Ask in plain language, get the answer in place.

Value

The people who own the budget are usually not the people who write queries. This puts the answer within reach of the admin instead of queuing behind an engineer.

Show

Data Usage ask Olly which team grew most this week, then ask the same thing from Quota Rules to show it follows you across surfaces.

Team API Keys in Data UsageRolling Out

See which caller spent your AI budget, not just that it was spent.

Before

Governance · Schema

Know and Guard Your Data

Schema Explorer ReportsShipped

Find the field you are actually looking for, including the ones buried inside arrays.

Before

Keypaths nested under array fields were invisible to search. Frequent-search reporting mixed every data type, so the top log fields were buried.

→
Now

Tree mode returns nested paths, and frequent-search is split out for logs so the ranking reflects one data type.

Value

Schema Explorer becomes usable against a real customer schema instead of a small one. Every cost and governance decision starts with finding the field.

Show

Schema Explorer search for a keypath nested under an array in tree mode, then open the logs frequent-search report.

CX-45369 · CX-45607 · no roadmap card yet PhoenixContent Structure
Reserved Fields for Every DatasetRolling Out

Set reserved fields per dataset, chosen from the fields you actually receive.

Before

One global reserved-field setting covered every dataset, so default/logs and a purpose-built custom dataset had to live with the same compromise.

→
Now

Each dataset carries its own reserved types, and the candidate list shows the fields actually observed in that dataset.

Value

Schema control per dataset without a global compromise. Showing observed fields means the choice is grounded in what is arriving rather than guessed from a spec.

Show

Dataspace Management pick a dataset, open reserved fields, and show the observed-field candidates for that dataset only.

↗ Roadmap card CX-45299 Phoenix
Dataset GuardrailsShipped

Catch a misconfigured dataset at creation, not when the data goes missing.

Before

A mis-typed bucket surfaced days later as absent data. Datasets in the reserved default/ dataspace had no quota ceiling at all.

→
Now

The Create Dataset drawer validates the bucket and the fully-qualified name up front, and default/ datasets accept quota limits like any other.

Value

Two failure modes that used to arrive as support tickets are now prevented at the point of configuration, on the dataspaces customers never created themselves.

Show

Create Dataset drawer enter an invalid bucket and show the rejection, then set a quota limit on a default/ dataset.

Coming Next

Monthly Team QuotaIn Build

Enforce against the monthly budget you actually contract on, not a daily slice of it.

Today

Quota is enforced daily. A customer who contracts monthly has to reason about a daily figure that does not match their commitment.

→
Coming

Month-to-date usage, monthly blocking and monthly notifications. Built on the backend, running in dry-run and flag-gated today.

Value

Removes the mismatch between how we sell and how we enforce, which is where most quota disputes start at renewal.

Show

Nothing live. Frame as coming next and say plainly that enforcement is in dry-run, so nothing fires on a customer today.
