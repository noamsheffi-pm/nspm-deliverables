Decided 2026-09-08

  1. 1

    A third mode on the control that already ships. The rule's filter row gets Named scope next to Filter expression. Builder stays disabled, as in production today. In the data model this is readScopeType: expr | scopeId beside today's readScope.

  2. 2

    The dropdown holds legacy scopes, reflected read only. AAA splits each legacy scope into a logs half and a spans half with their own IDs. On default/logs only the logs halves are offered. The "All other entities" default clones to both sides. No other named scopes exist yet.

  3. 3

    The ID is a reference, not a copy. Citadel stores readScopeId. The expression is shown but cannot be edited here. An edit through the old scopes API shows up here on its own.

  4. 4

    Detach cuts the link on purpose. "Detach and edit as expression" copies the text into Filter expression and drops the reference. Harel: a copy or a move would break the old API's view, a shared ID does not.

  5. 5

    Only default/logs and default/spans in phase 1. Switch to payments/logs above: the Named scope item is absent and nothing else changes. Phase 1 needs no scope API extension. AAA and Citadel agree a fixed access policy ID per team for the two datasets instead.

Open, shown here as one possible shape

  • A

    Schema context and autocomplete on a scope written outside the dataset. Harel flagged it, Ievgen and DLI still have to validate. The code read narrows it: the dataset editor already looks up schema by tier, not per dataset.

  • B

    A named scopes page in Citadel where an admin writes a reusable expression. Harel proposes it, Marco wants it as a separate project, Noam pushed back on the indirection. Not decided. The empty "Named scopes" group in the dropdown is the only trace of it here.

  • C

    Where the legacy scope is edited. "Open in Scopes" points at Settings › Scopes because that is where the old API is exposed today. Whether the page moves to Citadel ownership is phase 2.

  • –

    Not shown. The fixed per-team policy ID is a backend agreement. Whether it appears anywhere on screen was not discussed.
