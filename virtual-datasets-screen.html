Virtual Datasets

A virtual dataset is a name resolved at query time. It can resolve to a list of datasets, a name pattern, an entity type, or a full DataPrime query. Where a virtual and a physical dataset share a name, the virtual one wins.

⚠
Coralogix maintains three virtual datasets for you. Operational logs and log events are now separate entity types. Routing continues to write logs while fan-out writes logEvents. The predefined logs virtual dataset resolves to both, so the ~1000 dashboards, alerts and saved views written before the split keep returning the same data. Edit it to opt out.
