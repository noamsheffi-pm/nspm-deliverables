Dataset Aliases 6 / 50

An alias is a name that resolves to a source expression at query time. Every surface that accepts a source resolves through it: DataPrime, Explore, dashboards, alerts, background queries and saved views.

⚠
Coralogix maintains three aliases for you. Operational logs and log events are now separate entity types. Routing continues to write logs while fan-out writes logEvents. The predefined logs alias resolves to both, so queries, dashboards and alerts written before the split keep returning the same data. Edit it to opt out.
