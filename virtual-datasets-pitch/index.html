Problem today

Every query has to name every dataset.

source platform-api-logs, platform-auth-logs, platform-billing-logs, platform-dispatch-logs, platform-gateway-logs, platform-matching-logs, platform-notify-logs, platform-payments-logs, platform-routing-logs

Every query lists every dataset.

One customer writes the same nine dataset names into each query.

A new dataset breaks the list.

Each query, dashboard and alert must be edited by hand to add it. Missing one means missing data, with no error.

A saved query does not fix it.

It is a copy. When the list changes, every copy is still out of date.

Use case

Nine datasets, one name: platform_data

What happened
A transportation customer split platform data into nine datasets. Every query, dashboard and alert lists all nine. A tenth dataset means editing all of them.
What the page shows
An admin creates platform_data from the nine datasets. A user runs source platform_data in Explore and gets rows from all nine.
What the admin knows
One name covers the nine. The next dataset is added in one place, and every query that uses the name picks it up.
