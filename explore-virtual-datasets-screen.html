What this screen has to answer

The name is enoughThe user types one name instead of nine, and the platform expands it when the query runs.
The user can tell it is virtualThe picker row and the editor both mark it, so nobody mistakes it for a real dataset.
The user can see what it coversHover shows the definition and the datasets it resolves to now, without leaving the query.
The user can open itCommand-click on the reference opens the definition on the Virtual datasets page.
Partial access says nothing specificThe unreachable part returns nothing and the user gets one general notice. It never names a dataset.
No query permission, no nameWithout the query permission the name is absent from the picker and from autocomplete, and a query naming it returns nothing.
Source: 23-08 Harel and Redlus session, item R7 (hover shows the definition, command-click opens it, a chip marks a virtual reference on the DataPrime parser, Explore Log shows dataset type). Constraints from the same session: expansion is server-side, and a user without read must never learn a dataset is virtual. This is a reference for a design ticket. It is not production behaviour.
